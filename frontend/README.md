# 青笺前端

当前分支采用后端三阶段编排：前端组织上下文并预检/压缩，补齐原图缓存后，一次提交选图、正文、状态整理。正文仍逐字显示，阶段状态由后端推送。

详细协议、缓存回收与数据重置规则见 [后端编排与缓存](../docs/11-后端编排与缓存.md)。

- 数据库名保持 `roleplay-agent`，当前版本 v12；v8—v11 原地迁移并保留原件。完整备份当前为 v14，v9—v13 在导入入口迁移。
- 图片按 SHA-256 缓存在后端内存；原图仍长期保存在浏览器。默认空闲 30 分钟、绝对期限 2 小时，缓存总量 512 MiB。
- 刷新、切换应用和网络断开不会停止已接受的任务；回来后先读取完整快照再继续接收增量。主动切换角色/会话仍取消。
- 正文与整理结果保存后 ACK 删除；未取回结果最多保留 2 小时。后端重启会丢失内存结果，保留本地已有检查点。
- 整理失败不阻塞下次发送，只能手动重试最新步骤，不自动补做旧步骤。
- 浏览器长期保存角色、消息、原图、剧情、记忆、目标和摘要。不同站点地址或浏览器之间不自动同步。

剧情图草稿落库后自动检索三个姿势，用户手动选择；可改描述重检索、切换候选或关闭姿势参考。开启时必须指定人物参考图为 image2；关闭后动作描述仍加入普通提示词。检索失败不影响聊天与整理，刷新保留候选、选择和失败信息。

## 开发

```bash
npm ci
cp .env.example .env.local
npm run dev
```

默认通过 Next.js 转发至 `http://127.0.0.1:8080`，由 `BACKEND_URL` 修改；需要 Node.js 服务，不使用纯静态导出。

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
```

浏览器测试使用独立的模拟后端，不访问真实模型。模型窗口由后端 `CONTEXT_WINDOW_TOKENS` 指定，缓存与后台任务限制集中于 `roleplay.dispatch`。
