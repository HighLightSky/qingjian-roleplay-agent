# 剧情图开发与数据迁移计划

本版采用 [黑色画布与可编辑提示词方案](14-剧情图生成与视觉上下文方案.md)，调用 [图像编辑 API](13-生图服务API.md)。

## 本版调用迁移

正文移除生图职责，整理同一次输出 sceneImage，服务端还原为 scenePlan。普通聊天和手动整理重试均传正文检查点，并以同一浏览器事务提交状态及草稿。不新增 LLM 调用；模型、温度、输入及输出额度保持现值。整理不再通过正文的画面标记解析结果。

## v8 / v9 / v10 → v11 数据库

数据库名称仍为 roleplay-agent，新库直接建立 v11；旧库在同一 versionchange 事务内串联已有转换及本次转换。v7 及更早版本继续阻止升级并保留原库。

- 原地保留角色、会话、正文、原图 Blob、哈希、序号、版本、观察、摘要、画面草稿及用户编辑。
- v8 补齐持续视觉状态并建立生图表；v9 沿用原有画面计划与生成快照转换，然后执行本次转换。
- v10 草稿及生成提交中的参考移除 roles，保留 scope、顺序及其他字段，历史提示词和 effectivePrompt 原样保留。
- 旧整理结果补 scenePlan=null，表示当时未从整理生成画面；已有独立草稿继续保存，不自动补算。
- 中断旧 pending/running 操作及流式正文，清理 dispatch 恢复句柄；在途生成标为 unknown，保留提交内容，不自动重放。
- computed 整理的新画面引用参与资产计量与回收，草稿提交和领域提交同事务，失败可复用已计算结果。
- 升级不执行模型调用、图片解码或网络请求，任何失败整体回滚，禁止删库重建。

## v9 / v10 / v11 → v12 备份

导出统一 v12。旧备份依次通过现有转换和本次角色用途移除，之后按唯一新协议检查。保留原件、草稿、实际提交及其引用；嵌套的 computed 场景结果也校验来源和原图。导入不恢复远端任务句柄，仍执行原子替换。

## 发布与回滚

1. 升级前导出完整备份，等待当前聊天和生图任务结束，关闭其他旧标签页。
2. 同步部署前后端；新版原地升级后核对原件、编辑草稿、历史生成图及放弃记录，再导出 v12 备份。
3. 回滚时使用独立浏览器配置及升级前备份，不允许旧前端打开 v11 库或降级原库。

## 配置与生命周期

`roleplay.vision.max-images` 仍为数量唯一来源。生图能力中的 maxReferenceImages 由它减去一张黑图计算。

`roleplay.image-generation` 新增 default-width=256、default-height=512、dimension-alignment=32；前端通过能力接口读取。原有单图、请求、像素、输出、参考压缩、独立超时与缓存额度配置继续生效。

远端地址和 Token 仅在后端使用，需正确配置 JVM TLS 信任；不关闭证书校验。生成原连接和独立取消连接的行为不变：202 后等待原请求的成功或 TASK_CANCELLED，不提前释放名额。结果保留两小时；ACK 后释放结果。

## 自动化与人工验收

自动化使用 HTTP 夹具，不访问 GPU。覆盖真实 multipart 中文、纯黑首图与尺寸、空参考、编号自由文本、资源边界、幂等重连、取消竞争、编辑确认、草稿刷新、提交快照、放弃重生成、实际提示词目录、备份及数据库回滚。

执行 `mvn test`、前端 `npm test`、`npm run typecheck`、`npm run build` 和相关桌面/手机 Playwright 用例。真实服务的黑图重绘效果、实际输出画幅、人物连续性及停止生成另行人工验收；HTTP 夹具成功不代表画面效果验收通过。

2026-10-25 本次验证：`mvn clean test` 共173项，169通过、4项显式真实服务测试默认跳过；前端90项通过，类型检查与生产构建通过。桌面及手机共36项相关浏览器用例通过，覆盖v8/v9/v10原地升级、画面编辑、提交恢复、失败整理重试、附件与照片缺图。

另外显式运行 `StateUpdateLiveTest`，四项真实整理测试通过，其中一项覆盖换姿势、脱外套、坐椅阅读三组画面提示词；原有目标新增、关注点及进展证据各一次调用成功。结果可在 `target/scene-live-results.json` 查看。

`SceneGenerationLiveTest` 显式运行真实整理与图像服务，先生成一张人物参考，再生成上述三组画面，均得到256×512完整PNG。已查看人物参考与三张输出：主体身份基本延续，侧身扶窗、脱去斗篷及坐椅阅读的主要动作有体现；阅读图未明显呈现椅背上的斗篷，属于本次样例中的细节偏差。图片和整理结果保存在 `target/scene-generation-live/`。

真实服务测试默认关闭，分别通过以下命令启用，JVM信任库按部署证书配置：

```bash
mvn -Droleplay.live-llm=true -Dtest=StateUpdateLiveTest test
mvn -Droleplay.live-images=true -Dtest=SceneGenerationLiveTest test
```
